Praxura · Setup & Installation

Praxura-Box installieren

Die Box läuft auf einem Windows-PC oder Linux-Server in Ihrer Praxis oder auf Ihrem eigenen Hetzner-Server. Für die Einrichtung brauchen Sie Ihren Einrichtungscode; die ausführliche Anleitung erhalten Sie zusammen mit dem Code.

ℹ
Hinweis für dieses Gerät Auf diesem Gerät wird die Box nicht installiert — es nutzt sie später nur im Browser. Installieren Sie die Box auf einem Windows-PC oder Linux-Server.

Windows

Erkanntes System

PowerShell als Administrator öffnen (Startmenü → PowerShell → Rechtsklick → Als Administrator ausführen) und diese Zeile einfügen: 

& ([scriptblock]::Create((irm https://praxura.de/install.ps1)))

Linux (auch Hetzner Cloud)

Erkanntes System

Terminal bzw. SSH-Sitzung auf Ihrem Linux-Server öffnen und diesen Befehl ausführen: 

curl --proto '=https' --tlsv1.2 -fsSL https://praxura.de/install.sh | sudo bash

Voraussetzungen

Für einen reibungslosen Betrieb der Praxura-Box sollte das Zielsystem folgende Mindestanforderungen erfüllen:

Prozessor (CPU)
64-Bit Intel oder AMD (x86_64 / amd64). Kein ARM (keine ARM-Prozessoren, kein Raspberry Pi).
Betriebssystem
Windows 10 / 11 64-Bit mit im BIOS/UEFI aktivierter Virtualisierung, oder Ubuntu 22.04 / 24.04 bzw. Debian 12.
Ressourcen
Mindestens 4 GB RAM und 40 GB freier Speicherplatz auf der internen Festplatte bzw. SSD.

Lieber erst prüfen?

Sie möchten das Installationsskript vor dem Ausführen überprüfen? Laden Sie die Datei separat herunter und gleichen Sie vor dem Start die SHA-256-Prüfsumme ab.

Linux (auch Hetzner Cloud)

1. Skript herunterladen 
curl --proto '=https' --tlsv1.2 -fsSL -O https://praxura.de/install.sh
2. Prüfsumme vergleichen 
sha256sum install.sh
3. Ausführen 
sudo bash install.sh

Windows

1. Skript herunterladen 
irm https://praxura.de/install.ps1 -OutFile install.ps1
2. Prüfsumme vergleichen 
Get-FileHash .\install.ps1
3. Ausführen

In der Administrator-PowerShell .\install.ps1 ausführen — oder per Rechtsklick auf die Datei install.ps1 → Mit PowerShell ausführen (als Administrator).

Prüfsummen auf separatem Weg prüfen Die gültige SHA-256-Prüfsumme steht bewusst nicht auf dieser Seite, sondern in den Versionshinweisen auf GitHub oder kommt von uns auf separatem Weg (z. B. zusammen mit Ihrem persönlichen Einrichtungscode).
Fragen zur Bereitstellung? Wenn Sie Unterstützung bei der Installation oder der Wahl des passenden Servers benötigen, erreichen Sie uns per E-Mail unter kontakt@praxura.de.
